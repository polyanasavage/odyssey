# Odyssey

![Manifest V3](https://img.shields.io/badge/Manifest-V3-4285F4?style=flat-square)
![Version](https://img.shields.io/badge/version-2.0.0-8B5CF6?style=flat-square)

**Odyssey** — расширение для Chromium-браузеров, которое дополняет [Arizona LogsParser](https://arizonarp.logsparser.info/) инструментами анализа, копирования и оформления.

Автор: **Arlekin Polyana**

## Возможности

### Анализ данных

- Расчёт онлайна одного или нескольких игроков за выбранный период.
- Чистый онлайн с отдельными промежутками для будней и выходных.
- Скрытный сбор онлайна без прямой фильтрации по Nick_Name.
- Пакетный поиск наказаний и ответов на репорты.
- Сопоставление Nick_Name, ID, последнего и регистрационного IP.
- GeoIP-информация и приблизительное расстояние между IP-адресами.
- Многофакторный аудит входов Garant с уровнями риска, исключениями, TXT и формами `/banoff`.
- Поиск повторяющихся Email, Telegram, VK и IP.
- Проверка временных паттернов установки деталей тюнинга.

### Работа с логами

- Фильтр текста с режимами показа и скрытия строк.
- Генератор команд с подстановкой ников из таблицы.
- Сохранение шаблонов поисковых запросов.
- Копирование строки, ячейки или всех видимых логов.
- Маскирование IP, Email, Telegram и VK.
- Удаление грязных строк по готовым и пользовательским правилам.
- Сравнение регистрационного и последнего IP рядом с данными строки.
- Переход к дополнительной проверке адреса на Check-Host.
- Защищённое копирование без колонок «Данные» и IP.
- Запоминание штатного количества записей при переходах между страницами.
- Поиск типов логов по названию, коду, раскладке клавиатуры и пользовательским алиасам.
- Подсветка связанных строк подозрительной авторизации и короткой сессии.

### Интерфейс

- Два варианта тёмного оформления: классическая тёмная тема и тема Odyssey.
- Полная настройка цветов классической тёмной темы и цветового акцента Odyssey.
- Компактное отображение таблицы и управление колонками.
- Стандартное отображение IP LogsParser и расширенный режим Odyssey.
- Инструменты на странице или в окне Odyssey.
- Пользовательский favicon для LogsParser.
- Сохранение штатной пагинации, фильтров и элементов управления сайта.

### Информация о предметах

Названия предметов с маркером `[id: ...]` можно подсвечивать. При наведении Odyssey показывает изображение и описание предмета с помощью [items.sillyfrog.net](https://items.sillyfrog.net/) by **Abdula Shoev**.

## Установка готового релиза

1. Откройте страницу [последнего релиза Odyssey](https://github.com/polyanasavage/odyssey/releases/latest).
2. Скачайте `Odyssey-2.0.0.zip` из блока **Assets**.
3. Распакуйте архив в отдельную папку.
4. Откройте в Chromium-браузере страницу `chrome://extensions`.
5. Включите **Режим разработчика**.
6. Нажмите **Загрузить распакованное расширение**.
7. Выберите распакованную папку, внутри которой находится `manifest.json`.

После установки откройте [Arizona LogsParser](https://arizonarp.logsparser.info/). Пункт **Odyssey** появится в меню профиля справа сверху.

При первой установке автоматически включается только классическая тёмная тема. Остальные инструменты подключаются в настройках Odyssey.

## Обновление

Скачайте ZIP новой версии, распакуйте его поверх отдельной папки расширения и нажмите кнопку обновления на странице `chrome://extensions`.
